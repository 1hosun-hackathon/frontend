# 글적글적

직접 쓴 글을 AI 글과 비교하고 다듬는 글쓰기 훈련 서비스

주제 설정 → 초안 작성 → 비교 분석 → 다시 쓰기 → 훈련 완료

## 기술 스택

React · Vite · Tailwind CSS · React Router

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드: `npm run build`

## 참고

- 로그인과 AI 분석은 시연용이며 백엔드와 연결되어 있지 않습니다.
- 훈련 기록과 임시 저장은 브라우저의 localStorage를 사용합니다.
- 참고자료 첨부는 파일 선택과 파일명 표시까지 지원합니다.
